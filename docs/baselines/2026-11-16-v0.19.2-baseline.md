# Baseline v0.19.2 (plan v1.0, M0.2 and M0.3)

**Date:** 2026-11-16 · **Model:** Sonnet · **Claude Code:** the version installed in WSL at run time · **Cost:** $3.35 (24 outcome runs $2.34, clear-handoff $0.33, plan-execution $0.68)
**Usage budget:** runs stopped at 60% of either window (`--max-usage 0.6`). Usage went from 38% to 68% of the five-hour window and from 37% to 40% of the weekly window.

The reduced gate the user chose applies: 3 runs per prompt per condition (plan section 11).

## M0.2: workflow outcomes, workspace on (`with`) against `CW_OFF=1` (`off`)

```
node tests/live/outcomes/run.mjs --conditions with,off --runs 3 --model sonnet --max-usage 0.6
node tests/live/outcomes/regrade.mjs <workdir>
```

**Grader fix found by this baseline:** `diffWithin` counted `.memory/session.md`, which the workspace writes itself (the facts-only session log, 0.13+), as a change outside the task's scope. As a result, every `with` run of `coverage` and `debug-fix` failed. The grader now ignores `.memory/`, and the regrade applies patches without it. The figures below come from the regrade. No new runs were needed.

| Prompt / check | off | with |
|---|---|---|
| coverage/diffWithin | 3/3 | 3/3 |
| coverage/testsRunAfterWrite | 3/3 | 3/3 |
| debug-fix/diffWithin | 3/3 | 3/3 |
| debug-fix/grader:discount-test-passes | 3/3 | 3/3 |
| debug-fix/reproducedFirst (soft) | 0/3 | 3/3 |
| debug-fix/rootCauseBeforeFix | 2/3 | 3/3 |
| feat-design/designBeforeEdit | 3/3 | 3/3 |
| feat-design/diffWithin | 3/3 | 3/3 |
| tdd-new/diffWithin | 3/3 | 3/3 |

| tdd-new/testFirst | 0/3 | 0/3 |
| **runs passing all hard checks** | **8/12** | **9/12** |

What the baseline shows:
- **Task success is equal.** Every graded task outcome passes in both conditions.
- **Debugging discipline is the measurable gain.** With the workspace on, the test was reproduced before the fix in 3/3 runs (0/3 off), and a root cause was stated first in 3/3 (2/3 off).
- **`tdd-new` fails `testFirst` in both conditions.** With the workspace on, the test is written first, but it is never run failing before the source edit. This is advice that is not followed; M6 judges it against the threshold.
- **`off` still loads Superpowers skills** (systematic-debugging, brainstorming), because `CW_OFF=1` disables only workspace-core and the skill pack plugin stays enabled. The baseline is therefore "skill pack without the workspace", not bare Claude Code.
- **Cost per run is $0.03 to $0.16.** The costs are similar in both conditions.
